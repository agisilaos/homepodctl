# Report release failures for manual recovery

R14 reports the interrupted publication step, command outcomes, retained artifacts, and safe manual recovery instructions while retaining strict existing-tag checks. Shared process alignment moves tap branch selection, formula validation and its local commit before the first publication write; publication still pushes the version tag, then GitHub release/assets, then the Homebrew formula. Automatic resume was considered but deferred: proving artifact identity across partial uploads would add substantial complexity for an occasional failure, while builds of the same source can produce different bytes. Failed remote commands are reported as having an unknown outcome, and recovery guidance requires inspecting remote state and verifying original artifacts before any manual write; no automatic retries or rollback are introduced. The helper integrity manifest is a tooling record, not a publication-resume protocol.
